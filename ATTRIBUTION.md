# Attribution and reuse

This portfolio presents academic and internship projects associated with
Petros Charalampidis. Each project identifies its available authorship context.
The EEG project and CPU-performance analysis are collaborative work.

Code excerpts are identified by their original file and line range. They are
selected fragments of larger projects; surrounding interfaces, shared helpers
and any course-provided scaffolding retain their original provenance.
Original source comments and notices remain in the full-source assignments.

No blanket open-source license has been assigned to this mixed collection.
Existing notices and third-party/course/dataset terms continue to apply.
Public visibility alone does not grant a license to reuse all materials.
