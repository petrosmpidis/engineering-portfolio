# Digital Systems in Verilog

**Verilog · RTL Design · Arithmetic Datapaths · Register Files**

Academic digital-systems coursework associated with Petros Charalampidis.
The assignments cover an ALU, an accumulator-based calculator, a register
file and a small neural-network datapath.

## Selected design work

The public examples focus on:

- Signed addition/subtraction and overflow detection in the ALU.
- Reset behavior and dual-address writes in a register bank.

Read the [code excerpts](CODE_EXCERPTS.md) for the selected implementation
fragments and their surrounding context.

## Engineering topics

The coursework connects combinational arithmetic, clocked state, module
interfaces and datapath composition. The examples show specific design
decisions rather than a complete synthesizable system.

## Public contents and scope

This folder contains the overview and two short RTL excerpts. The complete
modules, calculator/neural datapaths, testbenches and report remain with
the full project. No HDL compilation, synthesis or FPGA validation was
performed while preparing this public presentation.
